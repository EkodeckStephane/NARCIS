# Project naming: NARCIS → ARCIS

The project was developed under the earlier name **NARCIS** (*Neural Adaptive Robust Coverless Image Signaling*). After the protocol and evaluation were substantially revised for the ACM TOMM version, the article/method name was changed to:

**ARCIS — Authenticated Robust Coverless Image Signaling**.

The current article title is:

> **ARCIS: Authenticated Robust Coverless Image Signaling with Finite-Index Feasibility**

## Why the repository still says NARCIS

The GitHub repository name `EkodeckStephane/NARCIS` and the implementation namespace `src/narcis/` are retained intentionally. Renaming them would invalidate or complicate previously recorded paths, scripts, checkpoints, citations, and experiment manifests. The stable repository URL therefore remains the public code/evidence URL cited by the TOMM manuscript.

## Which files are current

Use `paper/ACM_TOMM/` for the current ARCIS manuscript and submission snapshot. Files named `NARCIS*`, the Elsevier manuscript, and `paper/IEEE_TMM/` are historical revisions preserved for provenance.

The authoritative current aggregate results are summarized in the root `README.md`, `FINAL_EXPERIMENTAL_REPORT.md`, and `FACT_CHECK.md`.
